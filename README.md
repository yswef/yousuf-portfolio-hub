# Yusef Alhmzy — Portfolio (موحّد)

موقع شخصي متعدد الصفحات (الرئيسية، عني، السيرة، المشاريع، التطبيقات، الخدمات، المدونة، التواصل، صفحات مخصّصة…) بـ 5 لغات، مع لوحة تحكم بنظام وحدات.

- **الرفع على Hostinger:** `docs/DEPLOY.md`
- **ما الذي دُمج:** `docs/FEATURES.md`
- **دمج لوحة تحكم تطبيق آخر:** `admin/MODULES.md`
- **لوحات الإدارة (توليد البرومت + إدارة لوحات التطبيقات):** `docs/BOARDS.md`
- **ملخص للنقل لمحادثة أخرى:** `docs/PROJECT_SUMMARY.md`

تجربة محلية: `php -S localhost:8000` ثم `http://localhost:8000/install.php` (اختر SQLite).
