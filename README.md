# Yusef Alhmzy — Portfolio Hub

موقع شخصي ومنصة إدارة تطبيقات ومشاريع متعدد اللغات (`ar` / `en` / `es` / `fr` / `ja`) مبني بـ PHP 8.1+ و MySQL/SQLite، مع لوحة تحكم معيارية (`admin/`).

## أبرز المزايا
- **مزامنة ذكية مع GitHub:** جلب المستودعات وملفات `README` واكتشاف التطبيقات والإصدارات (المستقرة، التجريبية، والوسوم).
- **ترجمة عصبية تلقائية:** الكتابة بالعربية فقط وترجمة تلقائية لباقي اللغات عبر Google Neural (أو Gemini AI اختيارياً) مع حماية المصطلحات التقنية.
- **لوحات إدارة التطبيقات ومولّد المفاتيح:** إدارة إحصائيات وتراخيص وتوثيق كل تطبيق من مكان واحد.
- **التحديث الذاتي والنسخ الاحتياطي:** تحديث الموقع برفع ملف `.zip` أو مباشرة من GitHub من داخل اللوحة دون المساس بقاعدة البيانات أو الملفات المرفوعة.
- **تعليمات الموقع الكاملة:** متوفرة مباشرة داخل لوحة التحكم في تبويب **«📖 تعليمات الموقع»**.

## النشر والتشغيل
- خطوات الرفع على الاستضافة: [`docs/DEPLOY.md`](docs/DEPLOY.md)
- بناء أو دمج وحدات جديدة للوحة: [`admin/MODULES.md`](admin/MODULES.md)
- تجربة محلية سريعة: `php -S localhost:8000` ثم افتح `http://localhost:8000/install.php` واختر `SQLite`.
