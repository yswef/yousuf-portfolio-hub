# ملخص المشروع (للنقل إلى محادثة/نموذج آخر)

## القواعد المعطاة (حرفياً)
- لا تخمين ولا افتراض: إن لم يكن موضع الخلل مؤكداً فلا تعدّل؛ اسأل أو اطلب اختباراً.
- عند وجود خلل: لا تعدّل المنطق الموجود؛ اشرح خطوات تحديده بدقة، وقدّم سكربت (bash/PowerShell) أو دالة تُخرج ملف تقرير إن أمكن، وضع الحلول المقترحة في آخر الرد.
- عند الغموض أو الشك: اسأل قبل المتابعة.
- كل محادثة معزولة: لا تراجع الرسائل السابقة ولا تشر لمحادثات أخرى؛ المعلومات المهمة تُحفظ في ملف خارجي (هذا الملف).
- مع كل رد: أنشئ/حدّث ملف ملخص md بالهيكل: القواعد حرفياً، معلومات مهمة، تفاصيل مهمة كاملة، أسلوب كتابة الكود.
- ردود مختصرة: ما تم وفي أي ملف/دالة فقط، دون شرح إلا عند الطلب. قلّل استهلاك التوكنات؛ عند الارتفاع قدّم ملخصاً مفصّلاً لنقل المشروع.
- أرجع الملفات المعدّلة فقط (المسار + مكان التعديل). وثّق التعديلات الجوهرية بملف md. رسائل Git commits بتواريخ وأوقات واقعية ومتدرجة.

## معلومات مهمة
- المالك: يوسف الحمزي. يعمل حالياً في **مطعم حنيذ** (مُدخلة كخبرة حالية في وحدة المحتوى؛ المسمّى الوظيفي وتاريخ البدء فارغان ليكتبهما بنفسه).
- الهدف: دمج 3 مواقع شخصية (MY-Portfolio [PHP+SQLite]، portfolio [Astro+Cloudflare]، site [نسخة PHP منه]) في موقع واحد متعدد الصفحات على Hostinger (PHP 8.1+ / MySQL) بتصميم MY-Portfolio، مع لوحة تحكم بنظام وحدات قابلة للدمج مع لوحات تطبيقات أخرى.
- المصدر الأصلي المرفوع: `profiles.zip`. بيئة تطوير المالك: هاتف أندروويد + Termux، رفع عبر GitHub (تجنّب التنزيلات الكبيرة).

## تفاصيل مهمة كاملة
- **البنية:** `index.php` (راوتر `/{lang}/{route}/{arg}`) · `core/` (إعدادات، DB عبر PDO مع MySQL/SQLite، جلسات/CSRF/حدّ معدّل، i18n، Markdown، رفع صور، TOTP، مهاجرات) · `app/` (layout، parts، `pages/*.php`) · `lang/*.json` (نصوص الواجهة؛ المفقود يرجع en ثم ar) · `admin/` (index + core + modules + assets) · `assets/` · `install.php` · `cron_sync.php`.
- **الترجمة:** نصوص الواجهة في `lang/`؛ المحتوى في أعمدة JSON `*_i18n` (`{"ar":..,"en":..}`) تُقرأ بـ `tr($row,'title')`/`L()`؛ إعدادات الموقع بمفاتيح `name_ar`/`name_en`… عبر `setting_l()`.
- **الجداول:** settings, admins, rate_limits, audit_log (النواة) · projects, sync_log · apps, app_files, downloads · posts · items (type: service/skill/learning/experience/education/link) · pages · messages · visits.
- **الوحدات (admin/modules):** projects, apps, posts, content, pages, messages, analytics, settings, security, health, `_example` (معطّلة). العقد في `admin/MODULES.md`.
- **الأمان:** Prepared Statements، `e()` لكل إخراج، CSRF لكل POST، CSP صارمة، حدّ محاولات الدخول، `password_hash`، TOTP اختياري، رفع الصور بإعادة ترميز GD، منع تنفيذ PHP في uploads، حجب core/app/data/lang عبر `.htaccess`، CSV-injection guard.
- **اختُبر:** تثبيت SQLite، 13 صفحة × 5 لغات، تسجيل دخول/حدّ محاولات، CRUD للمقالات والمحتوى والمشاريع (رفع صورة)، الإعدادات، نموذج التواصل، `/dl/`، تصدير CSV، تقرير الفحص. **لم يُختبر:** MySQL فعلي على هوستنجر، مزامنة GitHub الحقيقية (الشبكة محجوبة هنا)، es/fr/ja لنصوص الصفحات الجديدة (تعود للإنجليزية عند غياب الترجمة).
- **مفتوح/لا يُخمَّن:** المسمّى الوظيفي في المطعم وتاريخ البدء؛ اسم الإنجليزية (Yusef Alhmzy في MY-Portfolio مقابل Yousif Alhamzi في portfolio — المُعتمد الأول وقابل للتعديل من الإعدادات)؛ مستويات المهارات (0 = بلا شريط).

## أسلوب كتابة الكود
PHP 8.1 صارم (`declare(strict_types=1)`)، دوال صغيرة بلا كلاسات، تعليقات إنجليزية مختصرة، رسائل الواجهة عربية، أسماء `snake_case`، كل SQL معامَل، كل وحدة manifest مصفوفة، مخرجات HTML عبر `e()`، CSS بمتغيرات ومنطقيات الاتجاه (`inset-inline`) لدعم RTL/LTR، JS بلا مكتبات وبلا inline scripts (CSP).
