# لوحات الإدارة (Boards) — دليل الاستخدام

قسم جديد في لوحة التحكم (`admin/modules/boards/`) يدير لوحة تحكم كل تطبيق من مكان واحد: توليد البرومت للموديل، استلام ملف اللوحة، مراجعة البيانات، التقارير، والتصدير/التحديث/الحذف.

## التدفق الكامل

1. **لوحة جديدة** (زر أعلى القسم) → نافذة منبثقة: اسم المشروع + نوع التطبيق (موبايل / سطح مكتب / الاثنين / بوت واتساب / إضافة متصفح / أخرى).
2. يُولَّد **البرومت** ويظهر في نافذة مع زر «نسخ البرومت» — انسخه وأرسله للموديل الذي يعمل على التطبيق.
3. تظهر **بطاقة فارغة** باسم التطبيق فيها منطقة سحب وإفلات لملف اللوحة المضغوط (zip).
4. أسقط الملف → يظهر زر **«＋ إضافة»** → ينقلك لصفحة بيانات اللوحة الكاملة:
   - **بيانات التطبيق**: الاسم، النوع، الوصف، التاجات، علامات البحث، الإصدار.
   - **الأيقونة**: تُرفع وتظهر في بطاقة اللوحة.
   - **GitHub**: رابط المستودع + زر «فحص المزامنة والإصدار» يتحقق هل المستودع مزامن وهل الإصدار مرفوع (عبر GitHub API).
   - **التوثيق**: هل للتطبيق موقع توثيق؟ نعم → اختر من المواقع المرفوعة (`/s/...`) أو ارفع zip موقع التوثيق هنا (يُنشأ موقع جديد ويُربط تلقائياً) + ملفات مرفقة إضافية.
   - **بيانات الموديل**: الصق JSON الذي يعبّئه الموديل واضغط «تطبيق بيانات الموديل» — تُملأ الحقول، ووظيفتك مراجعتها فقط.
   - **خريطة التثبيت (MAP)** + زر «التحقق من التثبيت» (يؤكد وجود الملف والخريطة الصالحة).
   - **الإحصائيات**: مستخدمون / تنزيلات / تراخيص / إيرادات / تقييم — تظهر في بطاقة كل لوحة منفصلة.
   - **بيانات المطوّر**: الاسم والبريد والملاحظات (تُضمَّن في البرومت وتوقيع الكود).
   - **التراخيص**: إنشاء ترخيص للتطبيقات المدفوعة (كود تلقائي إن تركته فارغاً) — متزامنة مع لوحة الأم.
   - **التعليقات والتقييمات**: مدونة موحّدة لآراء العملاء عن التطبيقات (اعتماد/حذف).

## أعلى القسم

- **الترتيب**: الأحدث/الأقدم إضافة، الأكثر مستخدمين/تنزيلاً/تراخيص، الاسم، آخر تحديث.
- **استخراج تقرير**: نافذة منبثقة — حدّد التطبيقات المستهدفة (أو «كل التطبيقات») والفترة (من/إلى) → تنزيل CSV.

## قائمة النقاط الثلاث (⋮) في كل بطاقة

| الزر | الوظيفة |
|---|---|
| نسخ البرومت | نسخ برومت هذه اللوحة |
| استخراج اللوحة (zip) | تنزيل zip: ملفات اللوحة + `board.json` + `map.json` + `prompt.txt` + `stats.csv` |
| تحديث اللوحة | رفع ملف zip جديد يستبدل الحالي |
| حذف اللوحة نهائياً | حذف اللوحة مع كل بياناتها وملفاتها (بتأكيد) |

## البرومت المولَّد

يُبنى تلقائياً حسب اسم التطبيق ونوعه، ويحتوي القواعد الصارمة التسع: حرية عدد الملفات، خريطة تثبيت مع تحقق، مزامنة لوحة الأم (الكود الوحيد للأم)، إحصائيات منفصلة لكل تطبيق، قاعدة بيانات واحدة بجدول مستخدمين موحّد (حساب منفصل لكل تطبيق بنفس البريد)، مدونة تعليقات موحّدة، قسم «التطبيقات الأخرى» داخل التطبيق، أيقونة البطاقة، مزامنة التراخيص، وتوقيع المطوّر في بداية ونهاية كل ملف.

## التخزين

- الجداول: `boards`, `board_files`, `board_comments`, `board_licenses`, `board_stats` (تُنشأ تلقائياً عند فتح اللوحة).
- ملفات اللوحات: `data/boards/<slug>/panel.zip` (مجلد `data` محجوب عن الويب).
- مواقع التوثيق المرفوعة من هنا تظهر في قسم «المواقع المنشورة» كالمعتاد.
