# سجل التغييرات — الدمج الأول

## ما تم
- موقع موحّد جديد (PHP+MySQL/SQLite) يجمع ميزات المشاريع الثلاثة، بتصميم MY-Portfolio. التفاصيل: `docs/FEATURES.md`.
- إضافة «العمل الحالي: مطعم حنيذ» في: الرئيسية (شريط «الآن»)، صفحة «عني»، السيرة (خبرة حالية) — قابلة للتعديل من اللوحة (الإعدادات ← العمل الحالي، المحتوى ← الخبرات).
- لوحة تحكم بنظام وحدات: النواة لا تتغير، وكل قسم/تطبيق جديد = مجلد في `admin/modules/`.

## قرارات تصميم (السبب)
- **روابط اللغة `/{lang}/…` بدل تبديل JS:** مؤشَّرة في محركات البحث، وتعمل دون JavaScript.
- **أعمدة `*_i18n` بصيغة JSON:** 5 لغات دون 5 أعمدة لكل حقل؛ يعود تلقائياً للإنجليزية ثم العربية.
- **جدول `items` واحد لعدة أنواع:** خدمات/مهارات/خبرات/تعليم/روابط بنموذج CRUD واحد.
- **المزامنة يدوية:** استضافة هوستنجر المشتركة بلا عمليات خلفية؛ الزر يعالج 25 مستودعاً كل ضغطة (تجنّب حدّ الوقت وحدّ GitHub).
- **تثبيت بمعالج `install.php`:** لا حساب افتراضي معروف (بدل `admin/Change@Me#2026` في نسخة Astro).
- **`crud_module`:** يحوّل وصف الحقول إلى واجهة كاملة؛ يقلّل كود كل وحدة جديدة إلى ~30 سطراً.

## ملاحظة إصلاح أثناء الاختبار
- اسم الدالة `PI()` يتعارض مع دالة PHP المدمجة `pi()` → أُعيدت تسميته `PN()`.
- معرّف وحدة CRUD يُستنتج من اسم مجلدها (`debug_backtrace`) بدل تمريره يدوياً.
- الجلسة لم تكن تبدأ في صفحة التواصل العامة (CSRF) → `start_session()`.

## إضافة: المواقع المنشورة + GitHub token من اللوحة + النسخ الاحتياطي الكامل
- **المواقع المنشورة** (`admin/modules/sites`, `core/sites.php`, `app/pages/docs.php`): رفع zip أو html، مجلد لكل موقع في `data/sites/<slug>/`، تُقدَّم عبر `/s/<slug>/…`؛ المواقع/الصفحات الخاصة تظهر بقفل 🔒 وتفتح للمدير فقط. ملفات php لا تُخزَّن ولا تُنفَّذ.
- **GitHub token/user**: يُضبطان من الإعدادات (يُخزَّنان في جدول settings ويتقدّمان على config.php).
- **النسخ الاحتياطي الكامل** (`admin/modules/backup`, `core/backup.php`, `core/restore.tpl`, `cron_backup.php`): zip واحد (ملفات + database.sql + restore.php)، احتفاظ بنسختين، حذف ما فوق 4 أسابيع بعد الإشعار، كرون أسبوعي.
