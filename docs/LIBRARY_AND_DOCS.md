# المكتبة التعليمية والتوثيق

## الفرق بينهما
| | المكتبة `/library` | التوثيق `/docs` |
|---|---|---|
| المحتوى | مواقع/صفحات جاهزة (دورات، خطط، مراجع) | نصوص Markdown لتوثيق تطبيقاتي ومشاريعي |
| الإدارة | لوحة ← المواقع المنشورة | لوحة ← التوثيق |
| الربط | مستقلة | اختياري بمشروع أو تطبيق (`project_slug` / `app_slug`) |

## إضافة مواقع للمكتبة
1. لوحة التحكم ← **المواقع المنشورة**.
2. اختر ملفاً أو عدة ملفات: `zip` = موقع كامل، `html` = صفحة منفردة. كل ملف يصير بطاقة.
3. البطاقة تفتح صفحة الدخول. غيّرها من «تعديل» ← «صفحة الدخول».
4. «قابل للنشر للجميع» غير مفعّل = تظهر البطاقة مقفلة ولا يفتحها إلا المدير.

مسار الخدمة: `/s/<slug>/` والملفات تُخزَّن في `data/sites/<slug>/` المحجوب مباشرة.

## ملفات php داخل المواقع
لا تُخزَّن ولا تُنفَّذ (تُتجاهل مع إشعار برقمها بعد الرفع). السبب أمني: php المرفوع يعمل بصلاحيات التطبيق نفسه. الخيارات الآمنة:
1. **تحويل إلى html ثابت** قبل الرفع (الأبسط، ويناسب الدورات والخطط).
2. **نطاق فرعي منفصل** بمجلد ومستخدم قاعدة بيانات خاصين، ثم ربط بطاقة المكتبة برابطه.

## ربط التوثيق بمشروع
لوحة ← التوثيق ← جديد ← اختر «مرتبط بالمشروع» أو «بالتطبيق». يظهر زر 📘 في صفحة المشروع/التطبيق تلقائياً.

الإعدادات ← «أظهر تبويب المدونة في القائمة».
